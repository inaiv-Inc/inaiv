<h1 align="center">inaiv</h1>

<p align="center"><b>The AI coding agent, powered by your inaiv subscription.</b></p>
<p align="center">SECURE · SOVEREIGN · ENTERPRISE-GRADE</p>

---

One subscription, every model. Usage is metered in rolling 5-hour and weekly
windows — no per-token billing. Sign in once in your browser and use inaiv
from the terminal, VS Code, or the desktop app.

## Install

### CLI

```sh
npm install -g @inaiv-studio/cli
inaiv auth login   # sign in with your browser
inaiv              # start coding
```

### VS Code extension

Install **inaiv** from the [Visual Studio Marketplace](https://marketplace.visualstudio.com/publishers/inaiv),
then press <kbd>Cmd</kbd>+<kbd>Esc</kbd> (macOS) / <kbd>Ctrl</kbd>+<kbd>Esc</kbd>.

### Desktop app

Download the installer for your platform from the
[latest release](https://github.com/inaiv-Inc/inaiv/releases/latest):
macOS (`.dmg`), Windows (`.exe`), Linux (`.deb` / `.AppImage` / `.rpm`).

## Highlights

- **Browser sign-in** — no API keys to copy around; approve once at
  [console.inaiv.ai](https://console.inaiv.ai) and every app is connected.
- **Your plan, everywhere** — run `/plan` in any app to see your usage
  windows and included models.
- **Share sessions** — `/share` publishes a read-only session link.
- **Enterprise-ready** — comped organization plans, model allow-lists,
  per-seat usage budgets, on-prem options.
